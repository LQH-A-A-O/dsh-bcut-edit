bcut-edit —— 用代码剪辑视频（必剪 + ffmpeg）
作者：涟崎桦    授权：MIT
============================================================

【30 秒了解】
这个技能能让 AI 直接生成必剪的剪辑工程：把素材拼起来、加转场、加中文字幕、
配 BGM，然后你在必剪里打开、微调、导出。也能不打开必剪，直接用 ffmpeg 出成品 mp4。


【需要你自己准备的东西】
1. Windows 电脑
2. 必剪（3.10.x）—— 已装好的
3. Python 3.9 以上，并装三个库：
       pip install requests pillow numpy
4. ffmpeg —— 完整版。技能里带了一键下载脚本：
       python get_ffmpeg.py
   （约 190MB，下到技能目录的 bin\ 里）
   已经装过 ffmpeg 的话，设个环境变量指过去就行：
       set BCUT_FFMPEG=D:\ffmpeg\bin\ffmpeg.exe

   ⚠️ 注意：录屏软件（比如各种游戏录制工具）自带的 ffmpeg 通常是精简版，
      缺 libx264、缺字幕滤镜，有的连 png/jpeg 解码器都没有。别拿它凑合。


【怎么装】
方式一（推荐）：把 dsh-bcut-edit-1.0.0.dspack 导入 DSH，技能会自动装好。

方式二（手动）：把压缩包里的 home\skills\bcut-edit\ 整个文件夹，
                拷到你 DSH 的 SKILLS 目录下（和别的技能并排）。
                拷完确认 SKILL.md 就在 bcut-edit\ 这一层里。


【装完先做这一件事】
    python "<技能目录>\bcut.py" doctor

它会告诉你：必剪装在哪、草稿目录在哪、ffmpeg 能力怎么样、本机有哪些转场可用。
输出里有 ❌ 就先解决它，别急着剪。


【怎么用】
    python "<技能目录>\bcut.py" doctor         体检
    python "<技能目录>\bcut.py" drafts         列出必剪里现有的草稿
    python "<技能目录>\bcut.py" transitions    本机能用哪些转场
    python "<技能目录>\bcut.py" demo -o plan.json    生成示例方案
    python "<技能目录>\bcut.py" build  plan.json      → 生成必剪工程
    python "<技能目录>\bcut.py" render plan.json -o out.mp4    → 直接出 mp4

详细的用法、方案格式、排错表都在 README.md 里，先看那个。


【两件必须知道的事】
1. 必剪没有命令行接口。所以"生成工程"是全自动的，但最后**点导出要你自己点一下**
   （或者让 AI 用截图点击的方式代劳，但那个不稳）。

2. 转场和片头片尾这些素材，必剪只把它**在界面里用过一次**的才下到本地。
   所以换台电脑后如果提示"本机没装"，去必剪里手动用一次那个转场就好。


【安全的】
这个工具往必剪草稿目录写东西时，**永远新建一个文件夹，不会改动你已有的草稿**。
自检脚本也是在一个临时沙箱里跑的，不会往你的草稿列表里塞东西。
